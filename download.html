نحوه نصب و اجرای ArtaDNS

مراحل ساده برای راه‌اندازی سریع نرم‌افزار

۱. دانلود فایل‌ها

فایل ArtaDNS_v1.0.0.zip را از دکمه بالا دانلود کنید. اگر در هنگام اجرا پیام نصب .NET Runtime (معروف به .NET Frameworks) دریافت کردید، فایل Runtime متناسب با ویندوز خود (۶۴ بیتی یا ۳۲ بیتی) را نیز دریافت نمایید.

۲. استخراج فایل‌ها

روی فایل ZIP دانلود شده راست‌کلیک کرده و گزینه Extract All یا Extract Here را انتخاب کنید. مطمئن شوید فایل‌های برنامه در یک پوشه جداگانه استخراج شده‌اند.

۳. نصب Runtime (در صورت نیاز)

اگر ویندوز شما فاقد Microsoft .NET 6 Desktop Runtime (معروف به .NET Frameworks 6) باشد، فایل Runtime دانلود شده را اجرا کرده و مراحل نصب را طی کنید. معمولاً ویندوز ۱۰/۱۱ آپدیت‌شده این پیش‌نیاز را دارند.

۴. اجرای برنامه

وارد پوشه استخراج شده شده و فایل ArtaDNS.exe را دو بار کلیک کنید. برنامه بدون نیاز به نصب (Portable) اجرا می‌شود.

۵. استفاده از برنامه

  • برنامه کارت‌های شبکه فعال را شناسایی می‌کند
  • با کلیک روی دکمه تست DNS، بهترین سرور برای خط شما پیدا می‌شود
  • نتیجه پیشنهادی را با یک کلیک روی کارت شبکه اعمال کنید
  • در صورت نیاز، می‌توانید DNS را به حالت پیش‌فرض (DHCP) برگردانید
نکته مهم: برای اعمال تغییرات DNS نیاز به دسترسی ادمین (Run as Administrator) دارید. برنامه به طور خودکار درخواست ارتقای سطح دسترسی را نمایش می‌دهد.

پیش‌نیازهای سیستم

محدوده سیستم‌عامل و سخت‌افزاری برای اجرای بهینه

  • سیستم‌عامل: ویندوز ۱۰ (نسخه ۱۸۰۹ یا جدیدتر) یا ویندوز ۱۱ - هر دو نسخه ۶۴ بیتی و ۳۲ بیتی
  • پیش‌نیاز نرم‌افزاری: Microsoft .NET 6 Desktop Runtime (معروف به .NET Frameworks 6) نسخه 6.0.10 یا جدیدتر (در صورت عدم وجود، لینک دانلود در بالا موجود است)
  • معماری پردازنده: x64 (۶۴ بیتی) یا x86 (۳۲ بیتی)
  • حافظه رم: حداقل ۵۱۲ مگابایت رم آزاد (برنامه بسیار سبک است)
  • فضای دیسک: حدود ۵۰ مگابایت فضای خالی برای فایل‌های برنامه
  • دسترسی شبکه: برای تست پینگ سرورهای DNS نیاز به اتصال اینترنت فعال
  • مجوز اجرا: نیاز به اجرای برنامه با دسترسی Administrator برای اعمال تنظیمات شبکه

راهنمای بررسی معماری ویندوز

برای دانلود Runtime مناسب، معماری ویندوز خود را بررسی کنید:

  1. کلیدهای Win + Pause/Break را بزنید یا راست‌کلیک روی This PC و انتخاب Properties
  2. در بخش System type بررسی کنید:
    • 64-bit Operating System → دانلود Runtime x64
    • 32-bit Operating System → دانلود Runtime x86

ویژگی‌های نسخه اولیه (v1.0.0)

  • شناسایی خودکار کارت‌های شبکه فعال سیستم
  • تست پینگ همزمان ده‌ها سرور DNS داخلی و بین‌المللی
  • نمایش نتایج با مرتب‌سازی بر اساس تاخیر (پینگ) و میزان قطعی
  • اعمال DNS انتخابی با یک کلیک (نیاز به دسترسی ادمین)
  • بازگردانی DNS به حالت پیش‌فرض ویندوز (DHCP) یا تنظیمات دستی
  • رابط کاربری کاملاً فارسی و راست‌چین
  • حالت Portable - بدون نیاز به نصب در ویندوز
  • نمایش جزئیات هر سرور DNS (نام، آدرس IP، مکان، پینگ، وضعیت)

سرورهای DNS پشتیبانی شده

برنامه شامل سرورهای معتبر زیر برای تست و انتخاب است:

  • داخلی (مناسب بازی و رفع تحریم): رادار گیم، الکترو، شکن، ۴۰۳، بگذر
  • بین‌المللی (مناسب دانلود، وب‌گردی، امنیت): Cloudflare (1.1.1.1)، Google (8.8.8.8)، Quad9، OpenDNS
پاسخ به ابهامات

پرسش‌های متداول درباره دانلود و نصب

پاسخ کوتاه به سوالاتی که ممکن است درباره دریافت و راه‌اندازی ArtaDNS داشته باشید

بله، نرم‌افزار ArtaDNS به صورت رایگان ارائه شده است و کاربران بدون پرداخت هزینه می‌توانند از تمامی قابلیت‌های آن برای تنظیم و پایش DNS استفاده کنند.
اگر پیش‌نیاز Microsoft .NET 6 Desktop Runtime (معروف به .NET Frameworks 6) از قبل روی ویندوز شما نصب نباشد، هنگام اجرای برنامه پیغامی دریافت خواهید کرد. در این صورت فایل Runtime متناسب با سیستم‌عامل خود (۶۴ بیتی یا ۳۲ بیتی) را از بخش بالا دریافت و نصب فرمایید.
کلیدهای Win + Pause/Break را بزنید یا راست‌کلیک روی This PC و انتخاب Properties. در بخش System type اگر 64-bit Operating System نوشته شده باشد، ویندوز شما ۶۴ بیتی است و باید Runtime x64 را دانلود کنید.
ابتدا اطمینان حاصل کنید که فایل ZIP را کاملاً استخراج (Extract) کرده‌اید. سپس فایل ArtaDNS.exe را راست‌کلیک کرده و Run as Administrator را بزنید. اگر پیام خطای .NET Runtime داد، فایل Runtime متناسب را از همین صفحه دانلود و نصب کنید.
نسخه فعلی ArtaDNS (نسخه 1.0.0) به صورت اختصاصی برای ویندوز ۱۰ (نسخه ۱۸۰۹ به بالا) و ویندوز ۱۱ توسعه داده شده است. پشتیبانی از ویندوزهای قدیمی‌تر در نسخه‌های آینده بررسی خواهد شد.
برای نصب خود برنامه (استخراج فایل ZIP و اجرا) نیازی به اینترنت نیست. اما برای تست پینگ سرورهای DNS و یافتن بهترین گزینه، اتصال اینترنت فعال الزامی است. همچنین در صورت عدم وجود .NET Runtime، برای دانلود آن به اینترنت نیاز دارید.
